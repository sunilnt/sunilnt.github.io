Digital Converting Job Changeover: What to Lock Before the First Saleable Roll

Plan a mid-web digital converting changeover around the incoming roll, finishing route, register, curing, slitting and final-roll specification.

1 September 20268 min readRoyal Coat

A digital press can deliver a short printed roll quickly and the finishing department can still lose the advantage during changeover. The usual cause is not one slow adjustment. It is missing job information: the wrong unwind direction, an unconfirmed eye mark, a varnish file that does not match the print revision, or a finished-roll requirement discovered after slitting has started. Treat the converting recipe as part of the job order. Lock the incoming roll, module route and saleable output before material reaches the line.

Define the saleable output before choosing the machine route

Start at dispatch. Record whether the job leaves the line in rolls, sheets or another format, then specify core, winding direction, maximum roll diameter, lane width, quantity per roll, splice rule, roll identification and packing requirement. A changeover is incomplete until the line can make that exact product, not simply a web that looks correct at the inspection point.

List every required operation in order: full or selective varnish, additional print, embellishment, die-cutting where applicable, inspection, slitting, rewinding or sheeting. PRATI describes DIGIFAST20000 as a modular mid-web platform that can be configured for printing, varnishing, embellishment and roll or sheet output across pressure-sensitive labels, in-mould labels, shrink sleeves and wrap-around work. The job route should use only the modules required for the approved product.

Release the incoming printed roll with usable data

The finishing operator needs the print revision, substrate, thickness, web width, roll length, repeat, lane plan, print direction, unwind direction and register-reference location. Add the ink or toner system, surface treatment where relevant, known splices and any quarantined section. Mark the reference edge physically and in the job record.

Check that the printed roll matches the data before threading. Measure the web and repeat, confirm the eye mark and lane count, and compare the varnish or embellishment artwork with the printed revision. If the line is expected to register to variable images, establish which mark or data feature is authoritative. A five-minute incoming check is cheaper than discovering a reversed roll or outdated finishing file after coating and slitting.

Record parent-roll identity throughout the changeover. Short digital jobs are often similar in width and appearance, which makes an unlabelled roll particularly easy to mix. The finished-roll record should always point back to the printed parent and approved file revision.

Build one recipe for the complete web path

Save the web path, active modules, tension zones, register sensor, print or varnish settings, curing condition, embellishment file, inspection reference, knife positions and rewind format as one controlled recipe. If part of the setup is kept on paper and part in the machine, use the same job number and revision on both. The operator should not have to reconstruct the last successful setup from separate notebooks.

PRATI's report from Labelexpo Europe 2025 says the DIGIFAST20000 flexo unit includes automatic ink setting and electronic adjustment of printing parameters. Automation reduces manual entry only when the stored values belong to the correct substrate, chemistry, artwork and running condition. Review the recalled recipe against the current job rather than accepting it because the name appears familiar.

Mark settings that cannot be transferred unchanged between materials. Web tension, curing, varnish laydown and rewind control depend on the actual substrate and finished construction. A previous recipe is a starting point, not permission to skip the first-roll checks.

Set register and finishing files from one approved reference

Choose the reference mark and define the permitted relationship between the printed image, varnish, embellishment and cut. Confirm the sensor can read the mark at setup speed and production speed without responding to neighbouring graphics. If the mark changes by design version, store an image of the approved mark with the recipe.

Load finishing files using controlled names that include the job, version and operation. A generic file called final is not a control. Display the selected version on the setup sheet and compare at least one distinctive feature with the approved artwork before running material.

Make the first correction at the source of the error. A register offset should not be used to hide a wrongly scaled file, an incorrect repeat or a web that is tracking against the wrong edge. Verify geometry and reference first, then use a controlled offset for the remaining process variation.

Prove the job in a fixed sequence

Run enough setup material to stabilise web handling and the active process, then check the operations in web-path order. Confirm tracking and tension, print or varnish position, coating appearance, curing, embellishment registration, cut or slit position, inspection response and finished-roll build. If several settings move together, the team will not know which change produced the acceptable sample.

Use the actual customer-approved substrate and chemistry for the release trial. Check both a representative image area and the most difficult feature, such as a fine reverse, a tight varnish knockout, a metallic effect near a cut line or a narrow outside lane. Retain the first approved sample with the job record.

Challenge the changeover at normal running condition. A result that holds only while the line is crawling has not proved register, curing or winding for production. Increase speed under the approved procedure and confirm the critical features again before declaring the first saleable roll.

Close the changeover with a first-roll release

The first-roll checklist should cover artwork revision, parent roll, active modules, register, varnish or embellishment, cure, slit width, roll direction, core, diameter, count or length, splice status, edge quality, winding condition and roll identification. Record the accepted sample and the person releasing it. Do not mix setup waste with saleable quantity.

After the job, save actual stable settings and note every deviation from the planned recipe. Record why the team changed tension, register, curing or rewind parameters. That explanation is more useful on the repeat order than a final number with no context.

Questions from production and purchasing teams

What to ask about digital converting changeover

What information should accompany a printed roll to digital finishing?

Provide the job and artwork revision, substrate, thickness, web width, roll length, repeat, lanes, print and unwind direction, register reference, parent-roll ID, splices and required finished format.

Should every available module be used in each job?

No. Define the approved product and use the module route needed to make it. Unnecessary stages add setup decisions and web handling without improving the job.

Can a saved recipe be loaded without another approval check?

Treat it as a controlled starting point. Confirm the substrate, chemistry, artwork version and finished specification, then release a new first roll under the current job order.

When does setup material become saleable output?

Only after the agreed checks for register, finishing, cure, slitting, winding, count or length and identification have passed and the first roll has been formally released.

What should be saved after the job?

Keep the final recipe, approved sample, parent and finished-roll IDs, actual settings, inspection or release record, setup waste and reasons for any changes made during production.
