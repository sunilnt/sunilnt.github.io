Label Inspection & Quality Control

How to Choose a 100% Print Inspection System for Labels

A practical guide to defining defect criteria, camera capability, editing workflow and validation when selecting 100% label inspection equipment.

13 August 20267 min readRoyal Coat

A 100% inspection camera can see the full web and still fail to keep a bad label out of the finished roll. The result depends on the defects it has been taught to find, the tolerances used for each job and what the rewinder does after an alarm. Begin the specification with the customer’s reject criteria and the roll-release procedure. Camera resolution and maximum speed come later.

Start with the customer's acceptance criteria

List the defects that would make a roll unacceptable: missing print, colour variation, register movement, streaks, spots, text errors, barcode problems, matrix faults, splices or variable-data mismatches. Define whether the requirement is general process monitoring, final outgoing inspection or a controlled compliance workflow for pharmaceutical, security or other critical labels.

Agree measurable tolerances wherever possible. A system cannot make a useful pass-or-fail decision when acceptable variation has not been defined. Different SKUs may need different zones, defect sizes, contrast thresholds and rules for static text, graphics and variable content.

  • Defect types and minimum relevant size
  • Critical and non-critical inspection zones
  • Barcode, OCR or variable-data requirements
  • Permitted colour and register variation
  • Customer rules for splices and roll release

Distinguish web viewing from automatic inspection

A web-viewing camera presents a magnified, repeated image to help an operator observe the process. Automatic 100% inspection continuously acquires the web and compares it with approved criteria or a reference, then records or signals detected deviations. Both approaches can be valuable, but they solve different quality-control needs.

For basic monitoring, operator viewing may be sufficient. When every label must be checked against defined rules, the converter needs automatic inspection with reliable defect detection, clear classification and traceable job data. The required level should follow customer risk rather than a broad claim that more automation is always better.

Test the real materials, graphics and running conditions

Evaluate candidate equipment with representative production rolls. Include fine text, low-contrast defects, reflective foils, clear-on-clear labels, dark backgrounds, varnishes, holographic elements and variable codes where these occur in the job mix. Lighting and image-processing performance can change materially with substrate and surface finish.

Testing should cover the intended web width and production speed, not only a slow demonstration. Confirm whether the system maintains the required inspection quality during acceleration, deceleration, splice passage and normal lateral web movement. Record which sample defects are consistently found and which create false alarms.

Design what happens after a defect is detected

Detection is only the first half of the process. Decide whether the finishing machine should stop at the defect, reverse to an editing table, allow the operator to remove material and splice, then reinspect the corrected section. Alternatively, inspection data from the press may guide a downstream rewinder directly to known defect positions.

The workflow must prevent an identified defect from remaining in an approved roll. PRATI describes configurations that combine full-web inspection with defect positioning, waste editing, splicing, counting, slitting and rewinding. Bidirectional inspection can support recursive checking where the application requires confirmation after correction.

  • Accurate defect positioning at the editing point
  • Controlled stop, reverse and restart sequence
  • Rules for removal, splice and reinspection
  • Roll mapping and defect-image storage
  • Final release record linked to the job

Balance sensitivity with usable production

An inspection system set too loosely can miss relevant defects; one set too aggressively may stop repeatedly for harmless variation. Both outcomes damage productivity. Establish approved tolerances during job setup, verify them against known samples and control who can change critical parameters.

Review false positives as process data rather than simply reducing sensitivity. Repeated alarms may point to unstable web guidance, lighting reflections, substrate variation or a genuine press condition. A well-designed recipe should be reusable for repeat work while still requiring confirmation when artwork, material or customer criteria change.

Specify the finishing platform around the complete job

Inspection should be evaluated with unwind diameter, web width, tension range, finished roll format, core sizes, slitting method, counting, maximum roll diameter and expected changeover frequency. Camera capability is of limited value if delicate film cannot be transported stably or if editing and rewinding create the production bottleneck.

Also define reporting, user access, job-recipe handling, connectivity, service support and future modules. The team can review sample rolls, defect policy, materials and finished-roll requirements to help structure an application-led equipment discussion.

Validate the process before releasing customer work

Create a qualification roll containing known examples of the defects the system is expected to find. Run it under defined conditions, document detection and positioning results, then repeat the test after operator training or material changes. For regulated work, align validation and records with the converter's quality system and customer requirements.

The strongest acceptance test follows one roll from approved reference through inspection, editing, slitting and final rewind. This confirms not only that the camera can see a defect, but that the production process reliably prevents it from reaching the customer.

Questions from production and purchasing teams

What to ask about label inspection & quality control

What is the difference between web viewing and 100% print inspection?

Web viewing helps an operator observe a repeated portion of the print. Automatic 100% inspection continuously evaluates the full web against defined criteria and records or signals detected deviations.

Does 100% inspection guarantee that every shipped label is defect-free?

Not by itself. The system must have suitable detection rules, stable web presentation and a controlled process for positioning, removing and reinspecting defects before the finished roll is released.

Should inspection equipment be tested at full production speed?

Yes. Test representative materials and defects across the intended width and speed range, including normal acceleration, splices and web movement, to confirm usable detection performance.

What information should be provided when specifying an inspection rewinder?

Provide materials, web and roll dimensions, defect criteria, artwork and variable-data needs, production speed, slitting and editing workflow, reporting requirements and representative sample rolls.
