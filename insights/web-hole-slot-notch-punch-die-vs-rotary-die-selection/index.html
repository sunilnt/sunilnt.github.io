Punch and Die Tooling Selection

One Hole, Slot or Notch in the Web? Decide Whether You Need a Punch-and-Die Set

Choose a punch-and-die set for a hole, slot or notch by defining the web, feature, machine interface, registration, waste removal and trial method.

8 October 20267 min readRoyal Coat

A converter may need one hang hole, vent, tamper-evident slot or locating notch in a web that is already printed and cut. Adding that feature to the main rotary die is not automatically the best answer. A separate punch-and-die set can handle a focused operation, but only when the material, machine interface, position, waste path and finished-product test are specified together. The decision should start with the feature and the production route, not with a tool name.

Define the feature and why it is needed

Mark every required hole, slot, notch or perforation on the approved drawing. Give its dimensions, tolerance, orientation, edge distance and position against the printed image or existing cut. State whether the feature is functional, decorative or part of a safety requirement. A hanging slot that carries product weight needs a different acceptance check from a small vent opening.

Send representative finished samples when they exist. If the feature must fit a peg, pin, sensor, fastener or downstream guide, include the mating part or its controlled drawing. Do not approve the tool from the opening size alone. Check how the feature behaves when the product is filled, folded, handled or used by the customer.

Identify which operation happens before and after punching. Printing, coating, lamination, die-cutting, slitting and rewinding can change how the web is supported and how accurately the feature can be located. The production sequence also decides where loose waste can go and whether the punched web remains strong enough for later tension and handling.

Choose a focused punch or a complete rotary pattern

Wilson describes a punch-and-die set as a matched pair in which the punch passes through the material and the die provides the opening that shapes the cut. Its guide positions this tooling for focused jobs such as holes, slots, notches, perforations and secondary operations. A full rotary die, by comparison, can carry the complete product pattern around the repeat.

Use that distinction as a starting point, not a shortcut. A separate set may suit one repetitive feature that must be added to several products or placed downstream from the main cut. A complete rotary die may be simpler when all features belong to one stable pattern and must remain registered as a single tool. The right arrangement depends on changeovers, web path, registration control and the number of product variants.

A punch can also work alongside the main rotary die. Wilson notes that converters may use the rotary die for the product shape and a separate set for a hang hole, tamper-evident slot or vent. Before adopting that arrangement, check that the press has a suitable station, controls the web at that point and provides a safe route for the removed piece.

Send the complete material construction

List every layer in running order: facestock or film, ink, coating, adhesive, liner, laminate, foil and any reinforcing patch. Add the supplier, grade and measured thickness of each relevant layer. Paper, film, foam, rubber and laminated structures do not shear or release waste in the same way, so the tool should be reviewed against the actual construction.

State whether the punch must cut through the complete web or stop before a liner or backing. Include the acceptable condition of the retained edge and the removed slug. A clean opening in the face with a damaged liner may still be a failed label job. A flexible package may need a different test for tearing, sealing or product contact after the feature is made.

Send enough production material for a controlled trial, including the print and surface treatment when they are present at the punching station. Do not substitute a plain development film for a coated or laminated commercial web without recording the change. The trial is useful only when its construction matches the job that will be released.

Specify the machine interface and waste path

Provide the press or converting-line make and model, station drawing, web width, running direction, available space, mounting arrangement and the components that locate and drive the set. Add the intended operating range and the web-tension condition at that station. A drawing of the required opening does not define how the tool will fit or remain aligned in the machine.

Explain how the feature is registered. It may follow a print mark, a main die-cut feature, a repeat signal or a fixed mechanical position. Record the permitted movement in the machine and cross directions and how the operator will measure it. If several lanes run together, identify every lane and the reference used to check position across the web.

Plan for the slug before approving the tool. State whether it drops by gravity, is extracted by air, remains attached for later removal or needs another controlled method. A loose piece can mark the web, enter the mechanism or appear in the finished roll. The trial should prove both the opening and reliable waste removal during repeated running.

Choose hardened or non-hardened tooling from the duty

Wilson offers hardened and non-hardened punches and dies. Its guide relates the choice to run length, material abrasiveness and the need for adjustment. Wilson describes hardened versions for demanding, high-volume work and non-hardened versions where field adjustment is important. Those descriptions should be checked against the converter's actual material and maintenance practice.

Give the supplier an honest production profile: expected batch size, frequency, total demand, material range, changeover pattern and the cost of a stopped line. Also explain who is authorised to adjust the tool and what measuring equipment is available. A version that can be adjusted on site is useful only if the adjustment is controlled, recorded and within the maker's instructions.

Ask how replacement components will be identified and matched. Record the punch, die and holder IDs as one controlled set, along with drawing revision, steel option and service history. Mixing similar-looking parts from different sets can change clearance and make a repeatable application difficult to diagnose.

Prove the cut on the line and keep the evidence

Run the intended construction through the complete operating sequence. Begin at a controlled condition, then inspect the opening, retained edge, liner or backing, slug removal, registration and web stability. Repeat the check after the line reaches normal production condition and after a planned stop and restart. One clean hand-fed sample does not prove continuous converting performance.

Measure the feature with the method agreed for production. Test its function with the real peg, pin, fastener, package or downstream equipment where applicable. Retain sequential samples from the start, stable run and any adjustment. Mark the web direction, lane, tool IDs, material batch and machine settings on the record.

Questions from production and purchasing teams

What to ask about punch and die tooling selection

What is a punch-and-die set in web converting?

It is a matched pair in which the punch passes through the material and the die provides the shaped opening. It is commonly used for a focused hole, slot, notch, perforation or secondary cut.

Can a punch-and-die set replace a full rotary die?

Sometimes, for one focused feature. It can also work alongside a rotary die that makes the main product shape. The production sequence, register and machine layout decide the better arrangement.

What material information is needed for a punch enquiry?

Send the complete construction, layer order, grades and measured thicknesses, plus the print, coating, adhesive, liner, laminate or reinforcement present at the punching station.

How should the removed slug be handled?

Define and prove a controlled waste path for the actual line. The slug may need gravity discharge, extraction, retained attachment or another approved method that keeps it out of the web and mechanism.

Should hardened or non-hardened punches be selected?

Base the choice on run length, material abrasiveness, downtime, adjustment needs and the supplier's review. Record the steel option and keep matched components together.
