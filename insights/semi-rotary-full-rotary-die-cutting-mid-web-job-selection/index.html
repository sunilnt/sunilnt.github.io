Mid-Web Die-Cutting Mode Selection

Semi-Rotary or Full-Rotary Die-Cutting for Mid-Web Jobs? Start With Repeat and Run Length

Compare semi-rotary and full-rotary die-cutting for mid-web work using repeat, run length, changeover, materials and finished-roll requirements.

22 September 20267 min readRoyal Coat

Semi-rotary and full-rotary die-cutting should not be compared from quoted speed alone. The useful question is which mode gives a stable cut, acceptable changeover and predictable output for the actual mix of repeats, run lengths and materials. Before discussing a machine configuration, put the job range on one sheet and identify where time is really being lost today.

Record the job range before selecting a mode

List the printed web widths, finished repeats, tool repeats, substrates, liners, adhesive systems and typical quantities. Separate work that repeats every week from occasional jobs. Include the smallest and largest repeat that must be covered, the number of designs per roll and the finished roll or sheet format. One average repeat hides the jobs that will decide whether the proposed configuration is practical.

Add the present sequence from printed roll to despatch. Record where inspection, coating, printing, embellishment, die-cutting, matrix removal, slitting and rewinding take place. If a roll passes through several machines, include the handling, queue and setup time between them. A die-cutting mode cannot be judged properly while the rest of the converting route is left out.

Keep a representative set of jobs for the technical discussion. The set should include a short run with a frequent repeat change, a normal production job, the longest steady run, the most difficult laminate and the job that currently creates the most waste or delay. This gives the supplier something more useful than a request for the fastest available machine.

Understand what changes when the repeat changes

In a full-rotary process, the tooling and web run continuously through the cut. In a semi-rotary process, the web motion is controlled around the cutting cycle so a tool can cover a range of job repeats within the machine's approved limits. The available range, tooling requirements and operating conditions are specific to the machine and must be confirmed for the jobs being considered.

Make a repeat table from live order history rather than relying on the artwork department's memory. For each repeat, note the annual number of orders, average run length, tool already owned and typical changeover. Then ask the equipment and tooling suppliers to mark which jobs fit each proposed mode without compromise. Jobs outside the stated window need a clear alternative route before the investment is approved.

Do not assume that one mode must handle every order. Some plants may keep a productive full-rotary route for long, repeated work and use semi-rotary capability where frequent repeat changes or shorter runs make it useful. The right split depends on the order book, existing tooling and the amount of time lost between saleable jobs.

Compare changeover and productive time

Build the comparison from the last good roll of one job to the first approved roll of the next. Include tool removal, tool fitting, web threading, register setup, matrix setup, slitter positioning, rewind preparation, inspection setup and approval waste. Maximum running speed begins to matter only after these steps are complete.

For a short run, ten minutes removed from a repeatable changeover can be worth more than a higher speed that is reached only briefly. For a long campaign, stable running speed, tool life and planned maintenance may carry more weight. Calculate both cases with the plant's own order quantities and labour pattern. Do not turn a demonstration speed into an annual output figure without allowing for the actual production mix.

Ask for a time study during the trial. Start with a known job, change to a different repeat and material, obtain an approved cut, then return to the first job using the stored settings. Record elapsed time, metres used and every manual intervention. That sequence shows whether the process is genuinely repeatable for the operators who will use it.

Test the tool, laminate and waste matrix together

A clean cut on one paper label does not prove the setup for a thin film, a difficult liner or a multilayer construction. Supply the exact laminate, liner, adhesive and printed web intended for production. Include the approved flexible die or solid tool specification and any known limits on matrix stripping, label lifting, adhesive bleed or liner marking.

Check cut consistency across the width and around the repeat. Inspect label release, liner condition, matrix behaviour, corners, small waste areas and the finished roll after it has been rewound. Run enough material for tension, temperature and waste handling to settle. A few hand-fed impressions do not represent a complete roll-to-roll converting job.

If several tooling choices are being considered, agree the test method before the trial. Keep the machine mode, material batch, speed and inspection rule identified on every sample. The decision should come from the approved finished result and the complete job time, not from the tool that produced the best-looking single label on the table.

Check the operations before and after die-cutting

Register control has to follow the printed web through coating, printing or embellishment and into the die-cutting unit. Note the register marks available on current work, the normal print variation and how a splice is handled. If the process needs spot varnish, registered white or embellishment, test those operations in the same production sequence rather than as separate showroom demonstrations.

Define the required output as carefully as the cut. Record slit widths, roll direction, core and maximum diameter, roll count, sheet size or stack format, defect-editing rule and traceability requirement. A line that cuts well but leaves another slow operation off-line may simply move the bottleneck to the next stage.

Approve the configuration from production evidence

Prepare an acceptance sheet before the trial. Include the required repeat range, approved materials, cut and liner standard, register tolerance, waste-matrix result, changeover sequence, output format and the measured production conditions. Mark which points are mandatory and which are options for later work. This keeps a technically attractive demonstration from replacing the actual buying criteria.

After the trial, compare full-rotary and semi-rotary routes job by job. Keep the sample rolls, settings, tool details, changeover record and approval notes. Any job not tested should remain an open item. Ask for the maintained operating window and training requirements instead of assuming that the best trial setting will cover every laminate and operator.

Questions from production and purchasing teams

What to ask about mid-web die-cutting mode selection

Is semi-rotary die-cutting always better for short runs?

No. It must be compared with the actual repeat range, tool position, material, changeover sequence and required output. A controlled job trial is the reliable basis for the choice.

Is full-rotary die-cutting only for long runs?

No. Run length is important, but existing tooling, repeat frequency, setup method, material and the complete converting route also affect the result.

What job data should be supplied before a mid-web die-cutting trial?

Send the web and repeat ranges, order quantities, substrates, liners, adhesive systems, tool details, register marks, finishing stages, output format and current waste or delay records.

Should the trial be judged by maximum speed?

No. Record changeover time, material used before approval, stable production conditions, cut quality, matrix behaviour and the finished roll or sheet.

Can the same die-cutting mode cover every laminate?

Do not assume so. Test the actual laminate, liner, adhesive and tool together, and have the machine and tooling suppliers confirm the approved operating range.
